## 작업 방식 / 사용자 선호

- 스택: Next.js + TypeScript (+ 필요하면 Supabase). 바이브코딩 경험, 웹 배포 후 PC. 인디게임 사이트 배포 (Google Play 안 함)
- 싱글 플레이, 마켓은 시스템 운영
- 그림: 본인이 그린 일러스트, 부위별 파츠 조합. 포즈 고정, 선화/명암 분리, 색은 코드로
- 개체 이름은 외국식 이름만 (한국식 이름 X)
- 유전을 깊게: 숨은 유전자, 족보, 근친, 혈통이 핵심

## 엔진 v0.6에 들어간 것

- 3종족 (인간/엘프/인어). 천사/악마는 특수 종족으로 추후 개발
- 대립유전자 출처 추적 → 조부모/증조부모 유전 표시 (3세대부터 자동)
- 외모 슬롯 5개 (귀, 눈 모양, 팔, 피부 무늬, 하체) 연관 유전, 묶음 풀릴 확률 10%. 인어 꼬리는 열성
- 종족 분류: 순종 → 하프 → 쿼터 → 다수 종족
- 신체: 키/체지방/근육 텍스트 라벨, 한성 형질 (가슴/성기 크기, 캐리어 표시, 옵션으로 끌 수 있음)
- 능력치 5종 (활력/근력/민첩/매력/마력), 종족별 특화
- 특수 혈통 (마법/불/얼음): 문턱 모델, 초대와 가문, 순도 3단계, 혈통별 문신 (위치 고정, 무늬 유전, 진하기 = 순도), 연계 혈통은 연계 문신
- 이형 (색소 결핍=알비노/루시스틱, 오드아이, 엔젤/데빌 쵸즌, 둘 다면 하이브리드): 유전 잘 안 됨, 소인이 쌓이면 천천히 상승
- 날개/뿔/헤일로 색과 하이브리드 형태는 숨은 유전자 → 외형 브리딩
- 트레잇 (보통/희귀/전설, 좋은/나쁜) — 목록은 예시
- 근친 계수, 페널티 곡선 (2대 연속 남매까지 약하게), 근친 부작용
- 임신: 하루 한 번 시도, 수정 확률 (종족 + 아빠 활력), 종족별 임신 기간, 쌍둥이/세쌍둥이
- 아기 단계 3일 (정보 숨김), 판매/사망 개체는 족보용 정보만 보관
- 유전자 키트: 문턱 근처의 숨은 이형 소인 공개 (게임에서는 아이템)
- 시드 랜덤, 압축 저장, 자동 테스트 12개

## 다음: 게임 내 시스템 (아직 안 정함)

1. 돈: 시작 자금, 마켓 구매가, 판매가 (혈통/순도/이형/트레잇/외모 희귀도)
2. 마켓 재고: 매일 몇 마리만 랜덤 등장
3. 농장 한도 또는 개체별 유지비 → 정기 지출 못 내면 게임오버
4. 목표: 도감 (색/파츠/혈통/이형/트레잇 수집), 가문 기록, 업적
5. 아이템: 유전자 키트 등
6. 임무 파견 (추후): 능력치별 임무, 돈 + 아이템, 파견 중 교배 불가, 임무 중에만 사망
7. 스프라이트 렌더러: 레이어 순서, 색 입히기, 문신 진하기, 좌/우 눈, 날개 좌/우
8. 게임 화면 + IndexedDB 저장
