# 브리딩 게임 (가제)

인간, 엘프, 인어를 교배하며 혈통을 키우는 싱글 플레이 브리딩 게임.
Next.js + TypeScript, 서버 없이 정적 파일로 내보내서 인디게임 사이트에 올리는 것을 목표로 한다.

## 실행

처음 한 번:

```bash
npm install
```

개발 서버 (코드를 고치면 바로 반영):

```bash
npm run dev
```

브라우저에서 http://localhost:3000 을 연다.

그 밖의 명령:

```bash
npm run build      # 배포용 정적 파일을 out/ 폴더에 만든다
npm run lint       # 코드 검사
npm test           # 유전 엔진 자동 테스트
npm run sim:farm   # 농장 밸런스 시뮬레이션 (150일)
npx tsx sim/economy_check.ts  # 돈 흐름 (유지비, 세금) 시뮬레이션
```

## 폴더

```
src/
  app/            Next.js 진입점 (page.tsx가 화면 전환과 저장 담당)
  components/     화면 조각 (타이틀, 농장, 개체 카드, 상세 패널, 임시 초상화)
  game/           게임 규칙: 돈, 슬롯, 난이도, 기록, 저장(IndexedDB), 색표
  debug/          디버그 리모컨 (게임과 분리, 통째로 지워도 됨)
  engine/         유전 엔진 (화면과 분리된 순수 TypeScript, 외부 의존성 없음)
tests/            엔진 자동 테스트
sim/              밸런스 시뮬레이션 스크립트 (게임에 포함되지 않음)
docs/             엔진 설명서 (engine-README.md, engine-HANDOFF.md)
```

엔진은 `src/engine`이 원본이다. 엔진을 고치면 `npm test`로 확인한다.

## 지금 되는 것 (0.5)

- 타이틀: 새 게임 / 이어하기
- 새 농장: 농장 이름, 난이도 (즐기는 모드 / 일반 모드)
- 농장: 인간 남녀 한 쌍과 500g으로 시작, 농장 10칸, 임신실 2칸
- 개체 카드 (임시 초상화), 상세 정보 (능력치 1~100, 종합 점수 = 평균, 외모, 트레잇, 유전 메모)
- 교배 칸 (엄마/아빠)과 임신실을 농장 화면에 항상 표시. 임신한 개체는 임신실로 옮겨지지만 농장 칸은 계속 차지함
- 육아실: 아기는 농장 칸을 차지하지 않음. 성체가 되면 칸이 필요하고, 모자라면 다음 날로 못 넘어감
- 하루 유지비 (점수, 트레잇, 이형, 특수 혈통에 따라), 매달 30일마다 세금 (800g부터 2배씩). 일반 모드는 세금을 못 내면 게임오버, 즐기는 모드는 잔액이 마이너스가 됨
- 농장 칸을 넘으면 다음 날로 못 넘어감 → 개체 판매 또는 칸 늘리기 (늘릴수록 비싸짐: 200, 300, 450, 680g ...)
- 마켓: 하루 5마리, 새로고침 하루 2번, 인간 70 / 엘프 20 / 인어 10, 종합 25~60, 희귀(이형/특수 혈통) 약 1%
- 가격 (임시): 인간 150~250g 안팎, 엘프 ×2.5, 인어 ×4, 트레잇 가감, 이형 +300~900g, 특수 혈통 +700~1000g (종족 배율 없이 더함). 판매가는 값의 40%(싼 개체) ~ 90%(1000g 이상)
- 마우스: 카드를 끌어 자리 바꾸기, 교배 칸에 놓기, 다른 성별 개체 위에 0.9초 대고 있으면 바로 교배 시도
- 키보드: 마우스 없이 전부 조작 가능 (`?`로 단축키 목록, 한 글자 단축키 끄기 가능)
- 다음 날, 출산, 아기 단계 (인간 2일, 엘프/인어 3일, 정보 숨김), 성체 알림, 농장 기록
- 족보 창 (상세 정보의 `족보` 버튼 또는 `P`): 증조부모까지 트리, 자식(짝별), 형제자매. 개체를 누르면 그 개체 중심으로 바뀜. 농장에 없는 개체는 점선, 마우스를 올리거나 포커스하면 농장에 있는지 말풍선으로 표시. 여러 번 나오는 조상(근친)은 ×2 표시
- 자동 저장 (브라우저 IndexedDB)

## 디버그 리모컨

`npm run dev`로 띄우면 왼쪽 아래에 `디버그` 버튼이 생긴다 (`F2`로 열고 닫기). 배포용(`npm run build`)에서는 숨겨지고, 주소 끝에 `?debug`를 붙이면 나타난다.

- 시간·돈: 날짜 넘기기(+1/3/7/30일, 직접 입력), 세금 전날로, 유지비·세금 없이 넘기기, 칸 초과 무시, 골드 더하기/맞추기
- 개체: 농장에서 고른 개체를 따라감. 바로 성체로, 출산일을 내일로, 오늘 교배 다시 허용, 돈 없이 내보내기, 이름, 능력치(유전자째 바꾸기 선택), 트레잇 켜고 끄기(유전자째)
- 추가: 종족, 성별, 목표 점수, 이형, 특수 혈통(초대)을 골라 무료로 농장에 추가
- 농장·저장: 농장 칸/임신실 늘리고 줄이기, 모드 전환, 게임오버 해제, 매물 다시 뽑기, 새로고침 횟수 초기화, 저장 파일 내려받기/불러오기
- 패널은 왼쪽/오른쪽으로 옮길 수 있다

떼어낼 때: `src/debug` 폴더를 지우고 `src/app/page.tsx`에서 `DebugRemote` import, `loadSave` 함수, `<DebugRemote ... />` 줄을 지운다.
